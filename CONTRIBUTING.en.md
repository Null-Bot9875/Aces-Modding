# Contributing

[中文](CONTRIBUTING.md)

Feedback about installing, editing, launching, debugging, and completing a playable content loop takes priority.

Include the game version, operating system, MOD directory structure, reproduction steps, expected result, actual result, and relevant logs. Do not submit game binaries, paid or unauthorized assets, account information, or other sensitive data.

Documentation changes should update the Chinese source first and synchronize the matching English file in the same change. Keep fields, identifiers, and paths unchanged.

Public documentation uses impersonal wording and avoids first- and second-person pronouns.

The code and documentation Pull Request process is not yet open. Licensing, formatting, testing, and review requirements will be added here when contributions open.
