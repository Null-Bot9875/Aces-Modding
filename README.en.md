# Aces Modding

> This English documentation was translated with AI. If anything is unclear or incorrect, please [open an issue](https://github.com/Null-Bot9875/Aces-Modding/issues); I will respond.

This repository provides MOD templates, configuration references, and concept guides for *ACE Strategy: Mecha Nova* (NOVA).

## Quick Start

- [Start Making a MOD](docs/en/getting-started.md): directory layout, configuration paths, installation, and verification.
- [`templates/card-pack`](templates/card-pack/README.en.md): Card MOD template.
- [`templates/enemy-pack`](templates/enemy-pack/README.en.md): a reachable battle node with an Enemy that uses a two-round action chain.
- [`templates/node-pack`](templates/node-pack/README.en.md): three-choice event node template.
- [`docs/en/config`](docs/en/config/): configuration files that MOD authors can use directly.
- [`docs/en/concepts`](docs/en/concepts/): concepts used by configuration files, such as Trigger, Area, and Attr.
- [`game-lua`](game-lua/README.en.md): Lua reference package for the current game version.
- [`game-config`](game-config/README.en.md): game configuration reference for the current version.

The English documentation index is at [`docs/en/README.md`](docs/en/README.md). The maintained Chinese source is available in [`README.md`](README.md).
