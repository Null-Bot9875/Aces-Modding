# Troubleshooting

The debugging guide will begin with the symptom you can actually see:

- The MOD does not appear in the game;
- the MOD is discovered, but a Card, Enemy, or Node is missing;
- the content appears, but its name, image, or behavior is wrong;
- battle results do not match the configuration;
- the game displays an error you do not understand.

## Current status

Exact log locations and step-by-step checks are in preparation.

When reporting a problem, keep the game version, MOD directory structure, steps, expected result, actual result, and relevant logs. Remove account details and other sensitive information, then choose “Bug report” in GitHub Issues.
