# Version-one limitations

Version one does not provide:

- Steam Workshop publishing;
- YooAsset MOD Packages or an author-side Package Builder;
- hot reload or runtime unloading;
- additional gameplay hooks beyond configuration content packs;
- compatibility guarantees for undocumented internal interfaces.

These limits keep the Alpha focused and are not permanent rejections. New capabilities should be driven by concrete MOD goals and author feedback.
