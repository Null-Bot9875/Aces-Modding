# What a MOD package contains

A configuration-first MOD usually needs to answer four questions:

- Who made this MOD, what is it called, and which game version does it support?
- Which Cards, Enemies, and Nodes does it add or change?
- Where should the game begin loading it?
- Which names and descriptions should players see?
