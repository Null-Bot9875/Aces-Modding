# What is currently available

The Card authoring path and integrated Node-and-Enemy example are version-one human-validation candidates. Human validation is incomplete for all three content types, so none is marked fully available yet.

| Area | Status | Author impact |
| --- | --- | --- |
| Getting started | Human-validation candidate | Installs and tests `card-pack` |
| General configuration format | First version available | Defines complete-row configuration batches |
| `card-pack` | Human-validation candidate | Provides a regular tactical Card, pool, and test reward; limited to test saves |
| Enemy configuration tutorial | Human-validation candidate | Covers Core base data, action chain, action pools, and Card references |
| Node configuration tutorial | Human-validation candidate | Covers a complete Node row, Enemy reference, and map refresh group |
| `enemy-pack` | Awaiting extraction | A separate template follows human validation of the integrated example |
| `node-pack` | Awaiting extraction | A separate template follows human validation of the integrated example |
| `complete-mod` | Human-validation candidate | Installable Node-and-Enemy example with no player Card |
| Manual testing checklist | First version available | Records Card, Node, Enemy, and disable-recovery results separately |
| Lua API tutorial | First version available | Documents Controllers, logging, lifecycle, and `require` |
| PNG and localization | First version available | Card PNG is supported; no language CSV generator is provided |
| Local tools | Not provided | There are currently no validation or packaging commands |
| Game Lua source reference | Not provided | For now, only use APIs already written in the documentation |
| Public license | Pending decision | No public copyable release before a formal LICENSE is added |

Card, Node, and Enemy status changes only after separate human installation and in-game tests. Automated checks, development-environment runs, and configuration queries do not replace human validation.
