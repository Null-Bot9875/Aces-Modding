# What is currently available

The first Card authoring path is available. Enemy, Node, complete example, and tool content remain in preparation.

| Area | Status | Author impact |
| --- | --- | --- |
| Getting started | First version available | Installs and verifies `card-pack` |
| General configuration format | First version available | Defines complete-row configuration batches |
| `card-pack` | First version available | Provides a regular tactical Card, pool, and test reward |
| `enemy-pack` | In preparation | No enemy example is available for entering battle yet |
| `node-pack` | In preparation | There is not yet a playable Node example |
| `complete-mod` | In preparation | The complete finished example has not yet been added |
| Lua API tutorial | First version available | Documents Controllers, logging, lifecycle, and `require` |
| PNG and localization | First version available | Card PNG is supported; no language CSV generator is provided |
| Local tools | Not provided | There are currently no validation or packaging commands |
| Game Lua source reference | Not provided | For now, only use APIs already written in the documentation |

Enemy and Node status changes after their configuration fields and in-game verification are complete.
