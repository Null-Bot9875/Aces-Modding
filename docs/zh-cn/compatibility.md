# 游戏更新与 MOD 兼容性

制作 MOD 时，只依赖文档明确列出的配置字段和 Lua API。游戏内部名称即使能够访问，也可能在游戏更新后改变。

## 声明支持版本

`mod.json.supportedGameVersions` 使用 `major.minor` 数组：

```json
{
  "supportedGameVersions": ["1.0"]
}
```

版本条目不能写成 `1.0.8`。复制模板后应改成目标游戏版本。

当前游戏版本不在数组中时，MOD 管理器显示 Warning，但不会仅因版本不匹配阻止启用。Warning 只表示兼容性没有得到声明或保证，仍需按人工测试清单验证。

## 可以依赖的内容

- 本仓库明确记录的 MOD 包结构；
- [通用配置格式](configuration.md)；
- 各内容教程明确列出的字段和引用规则；
- [Lua API](lua-api.md)；
- 对应游戏版本发布的 `game-lua` 压缩包，用于查阅同版本现有写法。

## 不稳定内容

- 文档没有列出的游戏内部 Lua 对象；
- 可偶然访问的 C# 类型；
- Core 配置中未作为作者合同说明的实现字段；
- 运行时绝对路径和内部缓存名称。

游戏更新后，先检查[更新记录](../../CHANGELOG.md)，再用同版本 `game-lua` 对照配置与调用方式，并重新执行[人工测试清单](manual-testing.md)。影响 MOD 作者的格式变化应在更新记录中说明。
