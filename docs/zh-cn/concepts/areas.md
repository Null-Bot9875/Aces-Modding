> Area ID 表示 Card、机体或玩家所在的战斗区域。

## Area ID 的引用入口

以下字段直接引用 Area ID：

| 引用字段                             | 作用                                       |
| -------------------------------- | ---------------------------------------- |
| `battle_target_def.config.area`  | 填写 Area ID 列表，决定 Target 从哪些区域查找目标        |
| `battle_effect_def.config.value` | `event=17` 时填写单个 Area ID，决定 Card 移动到哪个区域 |

## Area 枚举

| ID | 运行时名称 | 区域 | 说明 |
| --- | --- | --- | --- |
| `0` | `None` | 无区域 | 没有归入任何区域 |
| `1` | `Pool` | 牌库或卡组 | 牌库或卡组中的 Card |
| `2` | `Hand` | 手牌 | 手牌中的 Card |
| `3` | `Desk` | 弃牌堆 | 弃牌堆中的 Card |
| `4` | `Scrap` | 废弃区 | 废弃区中的 Card |
| `5` | `Equip` | 装备区 | 旧设计，不再使用 |
| `6` | `Stack` | 结算堆叠区 | 进入结算堆叠的 Card |
| `7` | `Base` | 机体基础区域 | 机体所在的基础区域 |
| `8` | `Player` | 玩家或机师 | 玩家或机师对象所在的区域 |
| `9` | `Ready` | 准备区 | 准备区中的 Card |
| `10` | `Shuffle` | 洗牌区 | 洗牌过程中临时存放 Card 的区域 |
| `11` | `Slot` | 设备槽 | 旧设计，不再使用 |
| `12` | `Trap` | 陷阱区 | 旧设计，不再使用 |
| `13` | `Grid` | 战场格子 | 战场中的格子区域 |
| `14` | `Drone` | 场上的机体或无人机 | 场上的机体或无人机 Card |
| `15` | `Queue` | 储卡区 | 储卡区中的 Card，等待后续结算 |
