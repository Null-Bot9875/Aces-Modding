# 节点池编号规则

游戏已有的节点池 ID 使用过一套便于策划阅读的编号约定。它可以帮助你看懂 `1401`、`1412`、`2002`、`2371` 等 ID，但不会改变节点池的运行方式。

## 常规节点池

常规节点池原本用 `14xy` 表示层级和内容规划。

前两到三位表示层级：

```text
140x → 第 1 层
141x → 第 2 层
142x → 第 3 层
143x → 第 4 层
144x → 第 5 层
145x → 第 6 层
146x → 第 7 层
```

末位原本表示内容：

```text
1 → 战斗
2 → 抉择
3 → 精英战斗
4 → 关底 Boss
5 → 特殊战斗位置
```

例如：

- `1401` 原本表示第 1 层战斗节点池。
- `1412` 原本表示第 2 层抉择节点池。
- `1414` 原本表示第 2 层关底 Boss 节点池。

## 特殊节点池

`200x` 用于不属于常规刷新编号的特殊节点池，例如引导、商店、补给和虫洞。

`2371`～`2376` 是第 7 层使用的固定节点列表。

这些范围只帮助阅读现有配置，不表示里面每个数字都有公开、稳定的用途。

## 这不是运行时规则

游戏不会解析节点池 ID 来判断层级或内容类型。现有节点池也可能被其他层复用，因此不能只看编号判断它影响哪些节点位置。

MOD 新增节点池 ID 时不要求沿用这套编号。只需要保证 ID 不与其他节点池冲突，并在 [`act_ep_map_def.refreshGroup`](../config/act_ep_map_def.md) 和 [`act_node_refresh_def.groupId`](../config/act_node_refresh_def.md) 中使用同一个值。

节点池成员、权重、机体限制和出现次数见 [`act_node_refresh_def` 配置参考](../config/act_node_refresh_def.md)。
