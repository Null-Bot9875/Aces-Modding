# Node 配置教学

这篇教程将把前面的内容组合起来，让玩家可以在地图上进入并完成一个新 Node。

内容包括：

- 选择 Node 中出现的敌人；
- 设置进入和完成条件；
- 设置战斗后的奖励；
- 把 Node 放到玩家能够到达的位置；
- 从进入 Node 一直测试到领取奖励。

## 当前状态
