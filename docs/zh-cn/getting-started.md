# 从这里开始

这篇教程通过复制示例、修改一项内容、加载 MOD 和确认结果，完成第一个 Aces MOD。

## 当前状态

本教程正在准备中，目前还没有可直接运行的模板。请不要复制空白占位目录开始制作。

教程开放后，按以下顺序操作：

1. 确认游戏版本和 MOD 存放位置；
2. 复制[完整示例](../../examples/complete-mod/README.md)；
3. 修改一张卡牌；
4. 启动游戏并进入示例 Node；
5. 查看修改结果；
6. 根据[调试指南](debugging.md)处理加载错误。

如需首个教程优先解决特定问题，可在 GitHub Issues 中选择“MOD 作者体验反馈”。
