# 从这里开始

这篇教程将带你完成第一个 Aces MOD：复制示例、修改一项内容、让游戏加载它，并确认修改已经生效。

## 当前状态

本教程正在准备中，目前还没有可直接运行的模板。请不要复制空白占位目录开始制作。

教程开放后，你将按这个顺序完成：

1. 确认游戏版本和 MOD 存放位置；
2. 复制[完整示例](../../examples/complete-mod/README.md)；
3. 修改一张卡牌；
4. 启动游戏并进入示例 Node；
5. 查看修改结果；
6. 根据[调试指南](debugging.md)处理加载错误。

如果你希望首个教程优先解决某个问题，请在 GitHub Issues 中选择“MOD 作者体验反馈”。
