# 当前限制

当前不能使用：

- Steam Workshop 发布链路；
- YooAsset MOD Package；
- 热重载或运行中卸载；
- 音频、Prefab、AssetBundle 等自定义资源；
- 配置内容包之外的额外玩法 Hook；
- 自定义 Skill、Target 和费用 Effect 的作者简化格式；
- 跨 MOD `mod://` 图片依赖；
- 文档没有列出的游戏内部接口。

当前 Card 教程只覆盖复用已有 Skill、Target 和费用 Effect 的普通战术 Card。

没有专用作者适配器的配置表仍可通过[通用配置格式](configuration.md)提交完整 row，但对应玩法是否真正使用该配置，需要完成各内容教程列出的游戏内验证。

必须使用其中一项能力时，可在 GitHub Issues 中选择“能力请求”，说明目标内容和当前阻塞。
