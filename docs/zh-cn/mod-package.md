# 一个 MOD 包含什么

一个配置型 MOD 通常需要回答四个问题：

- 这个 MOD 是谁、叫什么、适用于哪个版本；
- 它增加或修改了哪些 Card、Enemy、Node；
- 游戏应该从哪个入口加载它；
- 玩家在游戏里看到的名称和说明是什么。

## 当前状态

具体目录树和必填文件正在准备中。可用版本发布后，本页会提供：

- 一份可以直接复制的目录树；
- 每个文件的用途；
- 哪些文件必须存在；
- 多个 MOD 同时安装时的加载规则；
- 文件缺失或名称冲突时会看到的错误。

在此之前，请不要自行猜测文件名。可以先查看[完整示例](../../examples/complete-mod/README.md)了解这套资料将怎样组织。
