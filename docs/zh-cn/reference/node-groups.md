# EP 1061 Node Group 目录

本页公开 EP `1061` 当前地图使用的全部 `groupId`。Node Group 是地图已经设置好的内容入口；制作普通内容时只需选择现有 Group，不需要创建新的 Group。

接入方式：

```lua
return {
    installKey = "groupId",
    installValue = 1401,
    operation = "append",
    rows = {
        {
            groupId = 1401,
            nodeId = 990101,
            weight = 1,
            limitBaseId = {},
            nodeLimit = 1,
        },
    },
}
```

`installValue` 和 row 的 `groupId` 必须相同。`nodeId` 必须引用已经安装的完整 Node。普通内容优先使用 `append` 保留 Core 候选，再按设计设置 `weight`。人工测试可临时使用高权重，正式内容需要重新平衡。

## 命名和使用规则

EP `1061` 当前引用 44 个不同 Group。现有 ID 按以下方式组织：

| 范围 | 当前规则 |
| --- | --- |
| `1401–1465` | 普通路线内容组。基础规律为 `1400 + (层数 - 1) * 10 + 用途尾号` |
| 尾号 `1` | 当前主要放普通战斗池 |
| 尾号 `2` | 当前主要放随机事件池 |
| 尾号 `3` | 当前主要放特殊战斗池 |
| 尾号 `4` | 当前放固定单 Node，具体内容随层变化 |
| 尾号 `5` | 当前只用于少量特殊位置，不构成通用类型规则 |
| `2001–2008` | 跨层复用的功能 Node Group，例如入口战斗、商店、补给站、虫洞和同行 |
| `2371–2376` | 第 7 层固定终点序列 |
| `2100–2115` | `layer=9999` 的特殊剧情链，不是普通地图层位置 |

这套规则用于阅读现有地图，不是新 ID 生成规则。地图存在复用例外：`1431` 同时用于第 3、4 层，`1432` 同时用于第 4、5、6 层。选择位置时以本页实际使用表为准，不根据 ID 推导不存在的 Group。

## `replace` 与 `append`

| 操作 | 结果 |
| --- | --- |
| 省略 `operation` 或使用 `replace` | 删除目标 Group 的 Core rows，再安装 MOD rows；该 Group 的所有地图位置都使用新候选池 |
| 使用 `operation="append"` | 保留 Core rows并加入 MOD rows；所有使用该 Group 的位置都可能随机选中自定义 Node |

一个 Group 可能被多个位置甚至多层复用。修改前应检查表中的全部位置，而不是只观察首次出现的位置。停用 MOD 后，已经保存在旧战役中的地图结果不会自动重写；恢复验证需要冷启动并新建 EP `1061`。
