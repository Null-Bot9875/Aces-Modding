# 当前可以使用什么

Card 作者路径已经提供第一版。Enemy、Node、完整示例和工具仍在准备中。

| 内容 | 状态 | 作者侧影响 |
| --- | --- | --- |
| 从这里开始 | 第一版可用 | 可安装并验证 `card-pack` |
| 通用配置格式 | 第一版可用 | 可编写完整 row 配置批次 |
| `card-pack` | 第一版可用 | 提供普通战术 Card、卡池和测试奖励 |
| `enemy-pack` | 准备中 | 暂时没有可进入战斗的敌人示例 |
| `node-pack` | 准备中 | 暂时没有可游玩的 Node 示例 |
| `complete-mod` | 准备中 | 完整成品示例尚未加入 |
| Lua API 教程 | 第一版可用 | 已记录 Controller、日志、生命周期和 `require` |
| PNG 与多语言 | 第一版可用 | Card PNG 可用；语言 CSV 暂无生成工具 |
| 本地工具 | 尚未提供 | 目前没有校验或打包命令 |
| 游戏 Lua 源码参考 | 尚未提供 | 目前只能查看已写出的 API 页面 |

Enemy、Node 的状态在配置字段和游戏内验证完成后更新。
