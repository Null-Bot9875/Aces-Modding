# 当前可以使用什么

Card 作者路径与 Node+Enemy 联合示例已经形成首版人工验收候选。三类内容的人工验证尚未完成，当前不标记为正式可用。

| 内容 | 状态 | 作者侧影响 |
| --- | --- | --- |
| 从这里开始 | 人工验收候选 | 可安装并测试 `card-pack` |
| 通用配置格式 | 第一版可用 | 可编写完整 row 配置批次 |
| `card-pack` | 人工验收候选 | 提供普通战术 Card、卡池和测试奖励；只用于测试存档 |
| Enemy 配置教学 | 人工验收候选 | 说明 Core 基础数据、行动链、行动池和 Card 引用 |
| Node 配置教学 | 人工验收候选 | 说明完整 Node row、Enemy 引用和地图刷新组 |
| `enemy-pack` | 待拆分 | 联合示例通过人工验证后再提取独立模板 |
| `node-pack` | 待拆分 | 联合示例通过人工验证后再提取独立模板 |
| `complete-mod` | 人工验收候选 | 可安装的 Node+Enemy 联合示例，不包含玩家 Card |
| 人工测试清单 | 第一版可用 | 分别记录 Card、Node、Enemy 和停用恢复结果 |
| Lua API 教程 | 第一版可用 | 已记录 Controller、日志、生命周期和 `require` |
| PNG 与多语言 | 第一版可用 | Card PNG 可用；语言 CSV 暂无生成工具 |
| 本地工具 | 尚未提供 | 目前没有校验或打包命令 |
| 游戏 Lua 源码参考 | 尚未提供 | 目前只能查看已写出的 API 页面 |
| 公开授权 | 待确定 | 正式 LICENSE 加入前不作为公开可复制版本发布 |

Card、Node、Enemy 分别完成人工安装和游戏内测试后，再更新对应状态。自动检查、开发环境运行或配置查询结果不替代人工验证。
