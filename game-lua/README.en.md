# Game Lua Files

The current package contains 1,555 Lua files for Aces `1.0.9`, updated on 2026-10-23:

- [aces-game-lua-1.0.9.zip](aces-game-lua-1.0.9.zip)

The files keep the game's directory structure so MOD authors can look up existing logic. This package cannot be installed as a MOD.
