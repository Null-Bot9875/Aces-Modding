# 游戏 Lua 文件

当前提供 Aces `1.0.8` 对应的 Lua 文件压缩包：

```text
[aces-game-lua-1.0.8.zip](aces-game-lua-1.0.8.zip)
```

本目录不展开保存整棵源码目录；每个游戏版本只保留对应的压缩包。

游戏包中的 Lua 本身也是可读源码，只是以 `.lua.bytes` 文件放在游戏资源包中。这里的压缩包会恢复为普通 `.lua` 文件并保留原目录，省去自行解包、提取和改名的步骤。它不是反编译或解密得到的文件。压缩包排除了测试目录、根测试入口，以及包含内部加密键、登录凭据处理或内部网络信息的文件。

这些文件只用于查阅游戏现有写法，不代表稳定的 MOD API。
