# node-pack template

Copy this template when you want to build a new Node from an empty structure.

This template will contain the smallest MOD information, one Node, its enemies, completion rewards, and a way for players to enter it.

**Current status: In preparation.** There are no runnable files here yet, so do not copy this directory.

This is not the finished example. If you want to run a complete MOD first and then change it piece by piece, open the [complete example](../../examples/complete-mod/README.en.md).
