# node-pack template

This directory will provide a separate starting point for building a new Node from an empty structure.

This template will contain the smallest MOD information, one Node, its enemies, completion rewards, and a way for players to enter it.

**Current status: Awaiting extraction.** No runnable files are present.

Initial testing uses the [complete Node and Enemy example](../../examples/complete-mod/README.en.md). A separate template will be extracted from the same configuration after human validation, avoiding a second unvalidated structure.
