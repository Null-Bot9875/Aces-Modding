# node-pack template

Copy this template to build a new Node from an empty structure.

This template will contain the smallest MOD information, one Node, its enemies, completion rewards, and a way for players to enter it.

**Current status: In preparation.** There are no runnable files here yet, so do not copy this directory.

This is not the finished example. For a complete MOD that can be changed piece by piece, open the [complete example](../../examples/complete-mod/README.en.md).
